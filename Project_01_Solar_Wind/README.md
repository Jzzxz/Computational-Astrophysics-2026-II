# Project 01 — Solar Wind ODEs

## Overview

This directory contains **Project 01** of the Computational Astrophysics course.

The project focuses on the study of the **solar wind** through mathematical models based on **ordinary differential equations (ODEs)**. The objective is to apply the numerical methods developed throughout the course to a physical problem in astrophysics.

The project will involve the mathematical formulation of the solar wind model, the numerical solution of the resulting differential equations, and the analysis and visualization of the obtained results.

## Main Topics

- Solar wind physics
- Mathematical modeling
- Ordinary differential equations (ODEs)
- Numerical solution of ODEs
- Analysis and visualization of numerical results

## Project Structure

The materials, numerical implementations, results, and documentation developed for the project will be organized in this directory as the project progresses.
