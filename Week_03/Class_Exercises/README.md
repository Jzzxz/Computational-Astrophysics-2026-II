# Week 03 — Class Exercises

This directory contains the computational exercises developed during the third week of the Computational Astrophysics course.

The exercises focus on polynomial interpolation and numerical integration, including the implementation and application of different numerical methods to scientific problems.

## Exercises

The exercises in this directory are documented individually. Each exercise includes, when applicable:

- Problem statement
- Mathematical formulation
- Numerical approach
- Python implementation
- Results and visualizations
- Analysis of the numerical results
