# Week 03 — Polynomial Interpolation and Numerical Integration

## Overview

This week covers two fundamental topics in numerical methods: polynomial interpolation and numerical integration.

The first part focuses on reconstructing continuous functions from discrete data using polynomial interpolation methods. Direct interpolation, Lagrange interpolation, and Newton interpolation are introduced and compared.

The second part introduces numerical integration through physical and scientific problems. Different techniques for approximating definite integrals are studied, including Riemann sums, the trapezoidal rule, and Simpson's 1/3 rule.

## Topics

### Polynomial Interpolation

- Direct interpolation
- Lagrange interpolation
- Newton interpolation
- Divided differences

### Numerical Integration

- Physical problems involving integration
  - Motivation
  - Examples in science

- Numerical integration methods
  - Riemann sums
  - Trapezoidal rule
  - Simpson's 1/3 rule
