# Week 03 — Homework

This directory contains the homework problems corresponding to **Week 03** of the Computational Astrophysics course.

The homework focuses on the numerical methods introduced during the week, particularly polynomial interpolation and numerical integration.

The problems may involve the implementation and application of direct, Lagrange, and Newton interpolation methods, as well as Riemann sums, the trapezoidal rule, and Simpson's 1/3 rule.
