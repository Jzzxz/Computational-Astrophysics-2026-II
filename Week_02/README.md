# Week 02 — Numerical Differentiation and Finite Differences

## Overview

This week introduces numerical differentiation and the finite difference methods used to approximate derivatives computationally.

Starting from the definition of the derivative and its geometric interpretation through secant and tangent lines, finite difference approximations are developed using Taylor series expansions. Particular attention is given to the approximation error and its dependence on the step size $h$.

## Topics

- Introduction to derivatives
  - Secant and tangent lines
  - Exact derivative

- Finite difference methods
  - Motivation for finite differences
  - Taylor series expansion
  - Forward difference
  - Backward difference
  - Centered difference

- Numerical approximation error
  - Truncation error
  - Dependence of the error on the step size $h$
  - Order of accuracy
