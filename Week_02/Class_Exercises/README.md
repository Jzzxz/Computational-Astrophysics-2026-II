# Week 02 — Class Exercises

This directory contains the computational exercises developed during the second week of the Computational Astrophysics course.

The exercises focus on numerical differentiation and the implementation of finite difference approximations for derivatives.

## Exercises

The exercises in this directory are documented individually. Each exercise includes, when applicable:

- Problem statement
- Mathematical formulation
- Numerical approach
- Python implementation
- Results and visualizations
- Discussion of numerical errors
