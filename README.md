# Computational Astrophysics

This repository contains the coursework, numerical exercises, and homework assignments developed for the **Computational Astrophysics** course, offered as part of the **Master's Program in Astronomy at Universidad Nacional de Colombia**.

The course aims to introduce and apply **numerical and computational methods useful for solving problems in astrophysics**. Throughout the course, different numerical techniques are studied and implemented to address problems that may not admit analytical solutions or that require computational approaches due to their complexity.

The repository documents the exercises developed during class as well as the assigned homework, with emphasis on the mathematical formulation of each problem, the numerical method employed, its computational implementation, and the analysis of the obtained results.

## Repository Structure

The repository is organized by week:

```text
computational-astrophysics/
│
├── README.md
│
├── week-01/
│   ├── class-exercises/
│   └── homework/
│
├── week-02/
│   ├── class-exercises/
│   └── homework/
│
└── ...
```

Each weekly directory is divided into:

- **Class exercises:** numerical and computational problems developed during class.
- **Homework:** assigned problems and their corresponding numerical solutions.

Each exercise will include, when appropriate:

- Problem description and mathematical formulation
- Numerical method
- Computational implementation
- Results and visualizations
- Discussion of the numerical results

## Computational Tools

The numerical implementations in this repository are primarily developed using:

- Python
- NumPy
- Matplotlib
- Jupyter Notebook

Additional libraries and computational tools will be documented when required for specific problems.
