# Week 01 — Class Exercises

This directory contains the computational exercises developed during the first week of the Computational Astrophysics course.

The exercises focus on the numerical concepts introduced during the week, including numerical errors, floating-point arithmetic, error propagation, and Taylor series.

## Exercises

The exercises in this directory are documented individually. Each exercise includes, when applicable:

- Problem statement
- Mathematical formulation
- Numerical approach
- Python implementation
- Results and visualizations
- Discussion of the results
