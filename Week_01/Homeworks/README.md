# Week 01 — Homework

This directory contains the homework problems corresponding to **Week 01** of the Computational Astrophysics course.

The homework focuses on the fundamental concepts of numerical computation introduced during the first week, particularly numerical errors, finite-precision arithmetic, error propagation, and Taylor series approximations.

Unlike the shorter exercises developed during class, these problems require more time for numerical analysis, implementation, and interpretation. For this reason, they are assigned as take-home work.
