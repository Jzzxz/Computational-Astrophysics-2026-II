# Week 04 — Homeworks

This directory contains the homework assignments corresponding to Week 04.

The problems apply numerical root-finding methods to mathematical and astrophysical problems.

## Topics

- Numerical solution of nonlinear equations
- Bisection Method
- Newton-Raphson Method
- Secant Method
- Error estimation
- Convergence criteria
- Scarborough criterion
- Simultaneous equations

## Objectives

The main objectives of the homework exercises are:

- Implement root-finding algorithms directly in Python.
- Determine appropriate initial intervals or initial guesses.
- Analyze the convergence of iterative numerical methods.
- Apply stopping criteria based on numerical error.
- Compare different root-finding techniques.
- Interpret numerical solutions in the context of the original problem.

Whenever possible, the numerical algorithms are implemented manually in order to understand each step of the method instead of using predefined root-finding functions.
